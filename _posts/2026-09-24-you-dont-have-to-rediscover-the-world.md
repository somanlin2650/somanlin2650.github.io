自學最費力的時候，未必是看不懂書上的字。更令人困惑的是，每個字都懂，每一步似乎也跟得上，合起來卻不知道作者為什麼要這樣做。把書闔上，只記得幾個名詞；換一道題目，又得翻回原頁。

碰到這種情況，很容易認為自己基礎太差，於是找更多解說，把同一個定義再讀幾遍。但有時候，缺的恰好是定義之前的那一段：原來遇到了什麼麻煩，舊方法為何不夠，以及這個看來突兀的觀念，究竟替誰解決過什麼。

自學可以從這裡找到入口。人類已經累積下來的知識，可供借用的不只有結論，還有別人走向結論的理由。沿著那些理由重新思考，有機會讓原本只能照著做的事，逐漸成為自己能判斷、推演與修改的能力。

這也是學習既有知識的一項優勢。最初面對問題的人，往往連有沒有答案都不知道；後來的學習者卻可以借助留下的文字、圖與證明，挑選一條已有人整理過的路。學習不必假裝從未有人走過，把別人已經付出的年月再付一次。

因此，發現一項知識的方法，與讓另一個人學會它的方法，可以不同。研究者也借用前人的工作，學習者也需要查證；兩者的差別不在於誰才需要證據，而在於學習者常有一段現成的思考可以取用。暫時無法直接看懂某個問題時，可以先追問：一個人憑什麼看出問題該這樣處理？

## 課本從哪裡開始，並非小事
{: #s1 }

「理解」可以指很多事。能照著範例做，能向別人解釋，能在條件改變之後判斷原來的方法還適不適用，都算某種理解，卻不是同一種能力。學習的目的不同，需要走到的地方也不同。只想把眼前的工作做好，未必得先掌握整門學問的根基。

不過，有一種落差值得留意：知道規則，卻看不出為什麼值得訂這條規則。

定義與公式是前人整理過的成果。為了讓後來的人查閱、使用、檢查，許多猶疑和失敗會被省略，互相糾纏的問題也會重新排列。成品因此清楚了，初學者卻未必知道從哪裡進去。對作者而言不必再說的事，對讀者而言，可能正是缺掉的一步。

一份軟體功能的使用文件，就可能出現這種落差。文件會說明：交進什麼資料，會得到什麼結果，哪些情況算錯誤。這對使用與協作不可或缺。但若還不知道這項功能要處理什麼工作，再精確的規格也可能只是陌生名詞的清單。先看一次它怎樣解決問題，再回頭讀文件，同樣幾行字便有了用處。

知識的整理，可以看成一種壓縮。不過，壓縮不一定丟失資訊，一份嚴密的表述也不必然少了數學內容。被省掉的往往是引導讀者的線索。兩段文字可以表達同樣的關係，卻要求讀者付出很不一樣的理解成本。

保存與傳遞於是有了不同的要求。供熟悉的人查閱，一行公式也許就夠；要讓陌生的人取得使用它的能力，可能還需要展開那一行之前的幾個選擇。最終表述的順序，不一定就是理解最容易形成的順序。

## 一個看起來不該存在的數
{: #s2 }

第一次接觸虛數，常見的起點是一條規則：有個數叫 *i*，它的平方等於 −1。

疑問也立刻跟著來。以前學過的實數，不管正負，平方都不會小於零，現在怎麼忽然可以了？若想從日常物品裡找一個對應，更不容易：一個蘋果可以數，半個蘋果可以切，*i* 個蘋果要放在哪裡？

先把這個疑問留著，看看十六世紀的一道題目：

*x*³ = 15*x* + 4

左邊的 *x*³，是把三個 *x* 相乘；右邊則是 *x* 的十五倍再加四。題目要求能讓兩邊相等的 *x*。試一下 4 就知道，兩邊都是 64。答案明明可以是熟悉的數，當時已有的三次方程求解公式，在算這一題時，卻會出現「−121 的平方根」。[^bombelli]

已知答案就在那裡，一條通向它的計算途徑卻走不下去。對試圖理解這條公式的人而言，這比單純算不出來更難忽略。

拉斐爾・邦貝利（Rafael Bombelli）在 1572 年出版的《代數》中，系統地處理這類量的運算。用今天的記號來重述，先讓 *i*² = −1，便能用 11*i* 表示 −121 的一個平方根。那套公式接著要求：找出兩個數，使它們的立方分別等於 2 + 11*i* 和 2 − 11*i*，再將這兩個數相加。

依照新的規則展開乘法，恰好得到：

(2 + *i*)³ = 2 + 11*i*

(2 − *i*)³ = 2 − 11*i*

於是，公式需要的那兩個數，可以配成 2 + *i* 和 2 − *i*；加起來，*i* 消去了，剩下的正是 4。

讀到這裡，即使還不會自己展開計算，也已經能辨認那個困境：題目有普通的答案，計算途中卻需要容納一種新的數。允許它進來，訂清楚運算規則，原來中斷的計算便有機會繼續。

這並未回答虛數的一切問題，也沒有憑一個成功算例證明整套數學。它先回答了初學者很需要的一件事：為什麼有人願意認真看待這種東西。接著再學運算、證明與幾何表示，至少知道自己正在補足什麼。

這個次序影響了概念如何被理解。抽象概念不見得要先找到一個可以摸到的物體，才開始有意義。有時候，看見它保存了哪些關係，允許哪些操作，已經足以讓理解往前走。

## 概念的意義，可以在使用中長出來
{: #s9 }

「先用，再慢慢懂」容易被聽成一種退讓，好像完整的理解一定得在第一次閱讀時到位，否則就只能暫且將就。但對一個概念的理解，本來就可能逐步形成。起先只知道它如何運作，後來能辨認它與其他觀念的關係，再後來才看出同一種做法還能用在哪裡。

虛數便讓人有機會經歷這樣的變化。最初，*i* 只是一個遵守特定規則的符號；算過幾次，知道它怎樣與其他數配合；再接觸幾何表示，又多了一種理解運算的方式。這是今天的學習者可以採取的順序，不必聲稱每個人都會如此，或歷史上的發展恰好照著這份安排進行。

抽象還能做一件更深的事：把表面不同的問題，整理成可以共用一段推理的形式。假設一份食譜按人數等比例增加米量，兩人用兩百克，四人就用四百克；一張地圖若一公分代表一百公尺，三公分就代表三百公尺。米與道路毫不相像，但在這兩個設定裡，都可以先找出一單位對應多少，再由單位數求出總量。

掌握這個關係之後，便不必為每一樣東西重學一次算法。暫時略去物品的差別，保留計算需要的關係，使已學會的一段推理能在別處工作。當然，食譜裡的烹煮時間未必隨人數等比例增加；知道哪些細節可以略去、哪些不能，正是理解的一部分。

所以，遇到抽象觀念時，「它在現實裡是哪個東西」只是其中一個問題。還可以追問：它把哪些情況放在一起？保留了什麼關係？讓哪些原本必須分開處理的事，現在可以一起想？意義可以從這些連接中逐漸變得清楚。回頭再讀最初的定義，有時才會發現，原來那幾個字一直在說這件事。

## 嚴格的定義也有它要解決的麻煩
{: #s3 }

不過，只看見方法能用，還不夠。微積分處理的問題之一，是如何知道物體在某一瞬間的速度。用一段時間內移動的距離，除以花費的時間，算出平均速度；但「這一段」再短，也還不是「這一瞬間」。

處理這類變化的早期方法帶來許多成果，相關論證卻也受到質疑。1734 年，柏克萊在《分析者》中追問某些推導如何處理那個逐漸消失的增量：前面拿它來除，後面又讓它消失，究竟憑的是什麼？[^berkeley]

不用先學完整部微積分，也能聽出這個問題的分量。一個量若是零，就不能拿來作除數；若不是零，又不能只因為它很小，便說它根本不存在。算出的答案好用，仍有必要交代推理為何成立。

用現代的極限觀念，可以把問題說得更精確。以速度為例，每次計算的時間間隔都不為零；問題在於，當間隔愈來愈短，平均速度是否趨近一個確定的值。這與直接拿零來除，是兩回事。初學者若只看到正式定義裡一層套一層的條件，可能以為數學家刻意把事情弄難。先知道要防止哪一種含糊，便比較看得出那些條件在做什麼。

不同時期的數學家各有論證方式，後來的基礎工作也不是一次完成；「以前全靠直覺，後來才有嚴格數學」會把這段歷史說得太簡單。其中有一個值得保留的轉折：方法能做出成果之後，人們還得回頭追問，它究竟允許哪些操作。

從用途進入，再回頭讀定義，並不會降低對精確的要求。相反地，知道少一個條件會出什麼問題，那個條件才比較容易留下來，不再只是考前要背的字。

## 試著理解一個人還不知道答案的時候
{: #s4 }

「同理」通常用來談感受：一個人為何傷心，為何憤怒，為何對旁人看來微不足道的事如此在意。思考也有相似的處境。某個做法看似迂迴，可能只是因為後來的答案已經熟悉，忘了當時的人手邊沒有那些工具。

教育研究中有個詞叫 *epistemic empathy*，這裡暫譯為「認知同理」。Jaber 等人的研究用它描述：理解並重視一個人在建構、表達、檢驗知識時的認知與情緒經驗。他們探討的是教師如何理解學生。[^empathy]

把這個方向轉過來，便得到一種自學方法：由學習者理解提出觀念的人當時面對的處境。這是本文從認知同理延伸的主張；前述研究的範圍仍是師資培育。

其中要暫時放下的，是自己已經知道的答案。若一開始就把後來的工具塞回去，前人的選擇只會顯得笨拙。試著限制自己只能使用當時已有的觀念，才比較有機會看見：這一步為什麼有吸引力，那個疑問為什麼難以避開，以及某個看似多餘的區分究竟在保護什麼。

要做這件事，不必替幾百年前的人編內心獨白。比較可靠的問法是：根據留下的材料，他在處理什麼問題？當時有哪些做法？某個選擇解決了哪個困難，又帶來什麼新問題？史料沒有交代的部分，就留下空白；為了教學重新安排的步驟，也應說明那是重建。

回到邦貝利的例子，不必猜測他看見負數平方根時有多震驚。只要看清楚題目、公式和運算的關係，就能理解這項嘗試為什麼值得做。歷史提供了一個位置，讓今天的讀者暫時放下「這不是早就知道了嗎」的心情。

這也適用於數學之外。讀一段哲學論證時，先弄清楚作者在反對哪個主張，常比急著背下他的名言更有幫助。同一句話，用來回應不同問題，分量可能差很多。若連爭論的對象都不見了，只剩一句漂亮的結論，便容易替它安上一個作者從未打算回答的問題。

學習至此可以超過「知道作者的意思」，進一步重建他所使用的一段推理：如何選出相關的條件，怎樣由條件推出下一步，遇到反例時又應該修改哪裡。離開原文，換一個問題仍能做出這些判斷，原本只在別人的文字裡看見的思考，便開始成為學習者自己的能力。

## 廣讀可以留下的，比資料更多
{: #s5 }

如果學習包含這種換位置的能力，廣讀便有了另一層價值。接觸不同領域，除了多知道一些事，也呈現了不同的人怎樣決定「這裡值得追問」。

程式設計讓人留意一件工作怎樣拆開，部分之間必須約定什麼；統計促使人區分看到的差異與足以支持的推論。讀歷史，會碰到一句話如何受它的時代限制；讀哲學，會被要求把問題裡沒有明說的前提攤開。物理中的近似方法，則讓人看見忽略某些細節如何使問題變得可算，以及忽略到哪裡便會失準。

這些經驗累積起來，也會提供理解陌生觀念的線索。面對一個難以理解的選擇，可以進一步辨認：這是在省略暫時不重要的細節，還是在防止某種例外？選擇背後接受了哪些前提，又缺了什麼工具？廣度的價值因此包括進入他人的思考處境，理解答案如何形成。

譬如，一項工作總是遲交。借用系統設計的眼光，可以先檢查交接是否說清楚了：上一個人認為已完成的事，下一個人是否還得重做？換一種看法，又會問：所謂「總是」，究竟發生過幾次？最近接的工作是不是本來就比較難？這裡沒有哪個學科能憑一個比喻判定原因，但它們提供了不同、而且可以查證的問題。

借來的思路也會失準。人不能完全當成程式模組，幾次觀察不能冒充充分資料。跨過領域邊界時，得重新檢查哪些關係仍然成立。能聯想，是開始；能發現類比在哪裡失效，才讓這次借用變得可靠。

這種能力與「同理心提高智商」是不同的主張，後者需要另外的心理學證據。認知同理在此提供的是取用他人思考的入口：從問題的發現，到拆解、推論與修正，都可以成為學習的內容。經過練習與檢查，借來的思路才有機會成為實際可調用的能力。

## 教材需要留下的轉折
{: #s10 }

借用前人的思考，不要求把答案藏起來，讓學習者重新探索一遍。能直接教會的部分，可以直接傳授，省下的力氣則用來辨認更重要的關係。

這種材料可以稱為「壓縮過的認知重演」。它直接給出許多成果，同時保留幾個足以讓人接上推理的轉折：原來的問題是什麼，舊方法走到哪裡受阻，新做法改變了什麼，而這個改變又需要補上哪些規則。學習者不必等待幾十年，仍然可以理解為什麼下一步值得走。

前面的虛數例子，就是這種安排的一小部分。先看出 4 確實是答案，才會在意公式為什麼中途卡住；知道允許 *i* 參與運算可以接續計算，再讀它的規則，就有了一個具體的理由。只背下 *i*² = −1，也能開始做題，但這兩種安排留給學習者的東西並不相同。

這裡重演的是有助於理解的思考關係，不是把歷史原封不動演一遍。真實歷史有多人的交錯工作、走不通的岔路和難讀的舊記號，未必適合拿來當課程順序。老師與作者可以重新安排，直接採用較清楚的表示；只要交代哪些是史實、哪些是教學重建，就不必為了忠於年代而犧牲理解。

直接傳授與自己思考，可以在同一份材料裡合作。教材省去找路的年月，學習者則理解那些留下來的轉折，才能在路線改變時繼續推進。

## 追到哪裡，就可以先停下來
{: #s6 }

讀到這裡，最實際的疑問大概是時間。如果學虛數得先讀十六世紀代數，學微積分又要追幾百年的基礎爭論，還沒開始做事，日子就用完了。

追溯源頭不必成為自學的義務。許多時候，直接接受前人整理的成果很合理。先照食譜煮一頓飯，不必先懂所有食材的化學；依範例把程式跑起來，也可以早於完整掌握它的設計。能借助現成知識，是學習得以繼續的條件。

值得退一步的時候，是同一個地方反覆造成阻礙：題目稍微改動，就不知道怎麼做；規則背得出來，卻分不清哪裡能用；讀了三種解釋，仍覺得那個定義像是任意規定。這時再多讀一份相似的摘要，未必能補上缺口。

可以先找這個觀念要解決的一個具體問題。若還看不出必要，再查舊方法在哪裡受限。只退到足以接上目前的學習就好，不必為了懂一頁書，先讀完一整部思想史。

這其實是一個關於理解深度的選擇：眼前的目的，允許多少省略？偶爾套用一個公式，可以先掌握輸入、結果與適用條件；若要修改方法或判斷失敗原因，原來藏在公式裡的假設就得展開。理解深度不必固定，會隨著用途改變。

停止追溯的標準，也可以很樸素：能否說清楚它幫了什麼忙，依照現在的定義用一次，再指出一種不能照搬的情況？若做得到，就可以先往下走。哪天遇到新的障礙，再回來補。

自學因而包含對學習方式本身的判斷：現在這種學法還有沒有幫助？該再看一個例子、補一段推導，還是先動手使用？一味往深處挖，與一味收集摘要，都可能讓學習停住。知道何時接受壓縮、何時展開它，是需要另外練習的能力。

## 別只請 AI 再解釋一次
{: #s7 }

自學者可以用搜尋引擎找這些線索，也可以請 AI 協助整理。但如果只問「請用簡單的方式解釋」，很可能得到一份語氣更親切、缺口卻完全相同的摘要。

問法可以再具體一點。以下這段，把正在學的主題填進去便能使用：

> 學習主題：＿＿。目前程度：能跟著範例做，但不明白為什麼需要這個概念。請從符合這個程度的具體問題出發，說明不用此概念時有哪些做法、會遇到什麼限制，再引入概念並回到通用定義。交代所需的先備知識。涉及歷史時，附上可查核來源，分清史料記載與教學重建，不以故事補足未知。最後提供一道條件稍有變化的題目，暫不公布答案。

這樣問，是請它幫忙安排進入問題的順序。回答裡的年代、人物和引文仍得查核，推導也得檢查。敘事愈順暢，愈容易讓一個說得通的版本，看起來就像已經取得充分證據。

而最後那道題目，值得真的停下來做。看別人推理時，每一步都有前一步提示；自己動手，才會發現哪一段其實接不起來。

以剛才的 *i* 為例，若已學過括號乘法，可以換個式子，試算 (3 + *i*)²，並交代每一項從哪裡來。若目前只是想掌握概念，也可以先用自己的話說明：為何「實數裡找不到」不足以單獨否定擴充數系？接著再查，這種擴充怎樣保留原有的運算。不同目標有不同的練習，但都需要有一小段，不能靠照抄原文完成。

還有一道界線不能省略。理解一個人為何提出某個主張，不等於那個主張成立。數學仍須證明，關於世界的說法仍須證據。即使只是在學既有知識，也要辨認什麼是已證明的結果、什麼是近似、什麼還有爭議。前人的處境有助於解讀他的主張，卻不能替主張完成論證。

## 帶著借來的工具回來
{: #s8 }

這種學法讓「讀不懂」多了一種解釋。可能是基礎不足，可能是還沒花夠時間；也可能作者已經站在問題解決之後，讀者卻還不知道問題在哪裡。這時補上一段來由，比再添幾個術語有用。

《所見非全貌》反覆處理一個問題：人總是從有限的位置理解事物。背景、目的與手邊的工具，都會影響哪些事物進入注意。學習也一樣。作者認為顯然的一步，讀者可能完全看不見；讀者覺得毫無必要的區分，可能曾經替作者避開一個困難。

換位置，便有了很具體的意思：暫時按照對方掌握的條件、面對的問題來想，辨認哪些選擇因此變得合理，再把學到的推理帶回當前的處境。目的與條件一旦不同，借來的方法就必須接受新的檢查。理解一個人的思路，並不要求接受他的全部結論；原有做法也可以經過修正，留下其中有用的一段。

書裡的「保留、組合、回返」，在這裡連成一個學習過程：承接前人留下的成果，與已有的知識接合，使用時再回頭調整省略與假設。這套看法除了關心學習的內容，也檢查理解如何形成，以及形成理解的方法能否隨經驗而改變。

一個人留下文字、公式與圖，另一個從未見過他的人，便可能據此重建一段推理。留下來的當然不是整顆頭腦，但那段推理一旦能由讀者運用、檢查與改寫，就不再只屬於紙上的作者。人類累積知識的能力，也包含了這種思考能力的傳遞。

下次讀到一個怎樣也吞不下去的定義，可以先在旁邊寫下：「如果沒有它，哪個問題會變得難以處理？」找到一個足夠清楚的例子，再回來讀這一頁。有時，並不需要更多解釋，只需要讓原來的解釋有一個落腳的地方。
