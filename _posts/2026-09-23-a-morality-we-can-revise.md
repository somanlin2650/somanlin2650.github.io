道德不必先取得永恆的保證，才有遵守的理由。喝完飲料，空杯仍需妥善處理；排隊時，後來的人仍有理由等候。公共空間需要維持，合作需要彼此可以預期的行動，而日常生活沒有足夠的時間，讓每一件小事都從頭論證。

社會留下的規矩因此可以先被承接，逐漸成為不費力的習慣。問題在於，習慣也會誤判，規矩也可能失去原來的用途。一套能長久運作的道德觀，除了提供行動的依據，還需要讓錯誤有機會被看見，讓判斷與規範可以改變。

《所見非全貌》以「保留、組合、回返」處理理解如何形成與修正。道德觀是這套框架的一個完整應用：規範從社會進入個人生活，經由習慣產生判斷，再由新的經驗改變判斷方式。從一件地上的垃圾開始，便能看見整個過程，也能追問順應社會會在哪裡遇到困難。

## 規矩沒有從天上掉下來
{: #grounds }

「不要亂丟垃圾」涉及清潔、他人的勞動與公共空間的使用。這些理由已經足以支持妥善處理空杯，不必另外假定宇宙裡存在一個獨立的「亂丟垃圾之惡」。

本文採取道德反實在論的出發點，不把道德建立在獨立於人的終極根據上。這個名稱涵蓋不同主張，也不會自行決定生活應該怎樣安排。[^anti-realism]否定某種客觀道德，不能單獨推出應該順應社會，更不能推出只須顧及自身利益。往後的選擇仍需要各自的理由。

合作、信任與可預期的往來，是這套道德觀明確接受的價值。既然共同生活需要這些條件，一套大致可行的規範便有先拿來使用的價值，也能省去許多反覆協商的成本。

其中的價值承諾不能被「有效率」三個字取代。某種安排可能省下使用者的麻煩，卻把負擔交給別人；效率本身並未回答這種轉移是否值得支持。「有用」必須交代對誰有用，以及用來成全什麼。

這是一套從既定立場與價值承諾往下發展的生活方法。反實在論提供討論的出發點，實際規範則須接受用途與後果的檢查。框架能檢查這些連接是否成立，不能憑空決定所有人必須珍惜什麼。

## 社會留下的起點
{: #inheritance }

人很少先讀完一套道德理論，才學會等候、道歉、守約。通常是先在家庭、學校與日常往來中學著做，過了很久，才有機會說明理由。

杜威在《人性與行為》中，把取得群體道德的過程，比作承接群體的語言。孩子進入的生活，早已有一套正在運作的活動與要求。[^dewey]會說話的人不必親自發明語法，學習與人相處，也不必重建每一項禮貌。

對於熟悉、反覆出現，而且暫時沒有具體理由反對的日常規矩，先遵守是一種可行的安排。排隊時跟著隊伍走，約定時間便盡量準時，借用東西以前先問。這些做法既省去個人的計算，也讓往來的人不必每次重新猜測接下來會發生什麼。

沿用已有的答案，可以把時間留給尚未處理的問題。有限理性的研究提醒，取得資訊與比較選擇都受到能力、時間的限制。[^simon]要求每件事都先完成充分論證，看似嚴謹，卻可能使重要的問題也得不到注意。

但社會傳承並不全是試錯後的好答案。規矩也可能因權勢、恐懼、惰性或偶然而留下。某種安排維持很久，可能表示它方便合作，也可能只是承受代價的人始終沒有機會改變它。

承接社會規範，接受的是一批可以使用、也可以重查的起點。觀念不會因為來自父母、宗教或主流文化就自動失效，也不會因為普遍流行便得到保證。來源值得追查，卻不能獨自決定好壞。

## 把一件垃圾的判斷走完
{: #worked-example }

以下用一個假設情境展開判斷。一個人走過，地上留下一件包裝，旁觀者立刻感到不滿，認為對方不該亂丟垃圾。結論看似直接，實際上卻連接了好幾步。

首先，包裝被辨認成垃圾；接著，人與包裝先後出現，被解釋成那個人把垃圾丟下。「不要亂丟垃圾」這條規範再進入判斷，使眼前的行為成為值得制止的事。最後才是行動的選擇：提醒、指責，或先處理地上的東西。

在沒有爭議的日常情況裡，這些步驟不必逐一說出。規則早已熟悉，辨認垃圾便能迅速帶出清理的行動。這裡的「壓縮」，指許多背景與理由暫時退到注意力之外，只留下足以應付眼前用途的區分；它不是關於大腦如何儲存道德的完整科學解釋。

習慣也不必來自親自想通的理由。很多做法先由模仿與反覆練習形成，後來才有理由可說。習慣省下的，可能是前人的工作，也可能是一段從未仔細檢查的傳承。

現在多加一項材料：包裝其實從破掉的袋子滑落，當事人沒有察覺。

地上有東西需要處理，仍然成立；對方有意把麻煩留給別人的判斷，卻失去了根據。提醒袋子破了，便能處理眼前的情況，不必先把當事人歸為缺乏公德心的人。需要拆開的是「留下垃圾」與「故意留下垃圾」，原來維持清潔的規範仍然有用。

這是「保留」所面對的問題。若現場只被記成「沒公德心」，故意、疏忽與意外的差別便消失了。日後留下的可能只有對人的評價，沒有形成評價的材料。保留觀察與推測之間的區分，修正才有可以著手的地方。

「組合」出現在下一步。地上有包裝，可以支持需要清理，卻不足以單獨支持對人的譴責。從清潔需求接到責任判斷，還需要知道物品如何落地、當事人是否知情，以及是否有能力處理。兩項各自合理的想法，接在一起仍可能缺少必要的條件。

新材料使判斷改變，「回返」便開始發生。但修正若只停在當場道歉，影響仍然有限。下一次遇到類似情況，可以先提醒並容許回應；若要作出足以傷害名譽的公開指責，就需要更多查證。規範繼續沿用，啟動譴責的條件則經過調整。

一階更正處理的是這次看錯了人；二階修正改變的是往後如何從所見走到責備。若道歉之後仍以相同方式反覆誤判，經驗就只改了答案，沒有改變產生答案的方法。

情境還可以往前推。若同一處反覆出現散落物，就有理由查看垃圾桶是否溢滿、標示是否清楚，或清運安排是否出了問題。只問誰的道德不好，會把其他可能改善環境的做法排除在外。問題可能牽涉個人的態度，也可能需要改變整個處理方式。

接受規範、形成習慣、遭遇反例、改動判斷，再把改動帶回日常，至此才走完一圈。空間仍須維持清潔，判斷卻能少錯怪人，也更容易找到問題所在。框架的用途，可以由這些實際改變來檢查。

## 判斷的誤差由誰承擔
{: #costs }

日常判斷不可能次次精確。若每次丟垃圾，都得先計算污染、勞動與所有人的行為後果，一件可以完成的小事便可能變成沒有期限的分析。

容許誤差卻不能只看錯誤的次數。把空杯帶到錯誤的分類桶前，發現後重新分類；未經查證就公開指責一個人，也可能只算一次錯誤。兩者的代價、承受者和補救難度，卻相差很遠。

以習慣節省時間，並不因此取得把任何損失交給別人的理由。影響越大、越難補救，快速判斷就越需要停下來檢查。查證應放在可能改變重要結果的地方，而不是平均分配給每一件小事。

這種安排也不等於已經找到道德的最佳配置。不同價值未必有共同的衡量單位，更不能只憑幾個成功案例宣告整套方法最優。這裡追求的是在有限時間與能力裡可承擔的做法，並讓後來的結果有機會暴露不足。

## 反感為什麼不能直接成為禁令
{: #aversion }

垃圾的例子比較容易，因為清潔是相對明確的用途。生活方式的分歧更複雜：令人不舒服的，有時只是他人沒有按照熟悉的方式生活。

以對同性伴侶的態度作為檢驗。某些反感可能在成長環境中學會，即使後來說不出理由，那份不自在仍先出現。這裡要檢查的，是這種可能的心理反應，如何被用來支持規範。

感受是真實的，但首先說明的是感受者的狀態。從反感走到「對方不該這樣生活」，還需要另外的理由：哪項具體行為影響了誰？所擔心的後果有什麼根據？同樣的要求，用到異性伴侶身上是否仍成立？

若查到最後只剩不習慣，這份不習慣便不足以要求他人改變生活。文化可以解釋反感的來歷，不能單憑來歷替限制取得正當性。反過來，感受也不會只因受到文化影響便必然錯誤；需要檢查的仍是它支持了什麼，以及中間是否缺少理由。

沒有影響到判斷者本人，也不表示沒有值得關心的問題。其他人的處境可能尚未進入視野。但在取得足以支持限制的理由以前，反感可以先停留在感受，不必進入公共規範。

這不要求情緒在論證結束時立即消失。行動可以先改變，新的相處經驗再逐漸改寫過於粗糙的分類。只在心裡承認可能有偏見，對待他人的方式卻始終照舊，可修正性便還沒有進入生活。

這個例子中的二階反思，調整了感受取得裁判權的方式。感受可以提示某件事值得注意；從感受走到規範，仍須交代理由。

## 暫緩判斷也有適用條件
{: #attention }

每一場爭議都準備一個鮮明立場，並不是道德生活的必要條件。資料不足、眼前沒有需要作出的決定，而深入理解的代價又高，暫緩判斷可以讓注意力留給其他事情。

保留疑問，至少讓未知仍然可見。隨手接受最順耳的說法，卻可能把未曾了解的事情變成確定立場。此時停止下結論，比倉促替不熟悉的人與事分類更合適。

距離遠，不保證影響小。若某個決定正由當事人作出，或先前已承諾承擔責任，便不能只因問題麻煩而視為無關。是否投入注意，必須把決策位置與既有承諾一起算進來。

「先沿用」與「先不判斷」各有用途。站到隊伍前，需要決定如何排，通常可以直接採用熟悉的規矩；讀到陌生的爭論，卻未必需要立刻加入其中一方。前者借用已有做法，後者保留理解不足的狀態。

兩者都會隨情況改變。平常按先後順序辦事，遇到緊急需求，便可能重新考慮次序；原本遙遠的議題，一旦成為工作中的決策內容，也需要投入查證。注意力的分配可以調整，今日未處理的問題不因此永遠失去重要性。

## 修正需要條件，不只需要意願
{: #revision }

順應社會最難處理的問題是：連什麼值得懷疑，都可能由社會教會。既有規範若同時塑造了注意的方向，一些重要的事就可能始終沒有被看見。

承諾必要時反思，未必能解決這個困難。只接觸同一群人的說法，把異議一概視為無知，又讓提出疑問的代價越來越高，足以引起反思的材料便可能根本進不來。判斷權看似還在個人手裡，重新判斷的條件卻已消失。

可修正性因此需要平常就保留的餘地。重要分歧的原話與理由值得留下；影響他人的決定，需要讓受影響者補充材料；長期沿用的規矩，也需要偶爾檢查是否仍在處理原來的問題。這些安排需要時間，但不必把每件小事重新研究一遍。

前面的垃圾情境，還能展開個人以外的條件。假如管理規定只根據照片開罰，受指責者卻無處說明袋子破了、當時沒有察覺，即使承辦者願意公平處理，流程也可能只允許勾選處分。

新增說明欄位仍只是開始。誰會閱讀？可以補交什麼材料？確認誤判以後，有沒有人能撤回處分，並改變下一次的判斷方式？把申訴收進資料夾，與讓新材料改變決定，是兩件不同的事。這也不預先決定意外是否免除全部責任，而是先使不同情況能分開討論。

修正能力因此不只取決於意志。時間、資訊來源、他人的回應與制度允許的動作，都參與其中。只要求保持開放，卻拿掉這些條件，反思便容易退化成一句自我評價。

許多想法來自學習與社會塑造，這件事本身不構成拒絕它們的理由。若把所有社會影響都稱為「洗腦」，這個詞便無法區分不同的形成方式。封鎖資訊、懲罰疑問、阻止信念重新接受檢查，則確實破壞了這套道德觀願意順應的條件。接受塑造，不等於接受任何塑造方式。

思想自由的一項具體內容，也在這裡：觀念可以被傳授、接受、長久沿用，但新的理由出現時，仍有取得資訊、重新考慮與改變做法的餘地。這並未說盡自由的含義，卻是可修正性不能缺少的條件。

## 重視修正，本身也是一項立場
{: #commitment }

可修正性也有自己的來歷。使用的語言、辨認錯誤的方式，以及願意聽取理由的習慣，都可能受到社會影響。這套道德觀也沒有站在社會影響之外；用來檢查傳承的尺度，本身同樣需要接受檢查。

有來歷，不會使一項選擇失去全部理由。哪些誤判造成代價，哪些不同的說法有助於改善處境，以及往後的改變值得保留什麼機會，都仍能被提出、比較與質疑。理由可以繼續接受檢查，不表示當下沒有理由可用。

反思也不保證使人更好。學習與修正能力同樣可以被拿來更有效地追求傷害他人的目的。改變的能力與改變的方向，需要分開討論；方向仍取決於所重視的價值、願意承擔的後果，以及能否向受影響者交代。

這套道德觀的安排，是讓日常可行的做法逐漸成為習慣；遇到重要反例、規範衝突或代價改變，再展開習慣省略的部分。修正之後仍須練習，新的理解才有機會成為下一次的自然反應。理性與直覺由此互相改變，沒有一方永遠不會看錯。

回到最初的空杯，妥善處理仍是可以沿用的做法。看見別人留下物品時，則需要分清觀察與推測；既有規定處理不了某種情況時，問題也能回到規定本身。

一套可以修改的道德，讓生活不必每天從頭開始，也讓後來才知道的事情，仍能改變接下來的做法。
